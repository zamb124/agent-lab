# Json Tree

Платформенный компонент `platform-json-tree`: дерево JSON с значениями листьев и превью base64-картинок.

Статус документации: **production**.

## Запуск тестов

```bash
npm run test:ui-kit -- tests/ui/design-system/components/platform-json-tree/contract.spec.js
uv run pytest tests/ui/design-system/components/platform-json-tree/playwright.spec.py -v
```
