# ECharts Host

Платформенный компонент `platform-echarts-host`.

Apache ECharts в Lit: lazy script loading, ResizeObserver, dispose.

Статус документации: **backfill**.

## Запуск тестов

```bash
npm run test:ui-kit -- tests/ui/design-system/components/platform-echarts-host/contract.spec.js
uv run pytest tests/ui/design-system/components/platform-echarts-host/playwright.spec.py -v
```
