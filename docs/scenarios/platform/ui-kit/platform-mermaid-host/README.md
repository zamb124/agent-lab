# Mermaid Host

Платформенный компонент `platform-mermaid-host`.

Mermaid SVG в Lit: lazy script loading, antiscript, platform theme.

Статус документации: **backfill**.

## Запуск тестов

```bash
npm run test:ui-kit -- tests/ui/design-system/components/platform-mermaid-host/contract.spec.js
uv run pytest tests/ui/design-system/components/platform-mermaid-host/playwright.spec.py -v
```
