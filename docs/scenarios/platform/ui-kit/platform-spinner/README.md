# Spinner

Платформенный компонент `platform-spinner`.

Единый спиннер платформы: вращающийся логотип Linnex. Заменяет `glass-spinner` и `app-loader`.

Статус документации: **backfill**.

## Запуск тестов

```bash
npm run test:ui-kit -- tests/ui/design-system/components/platform-spinner/contract.spec.js
uv run pytest tests/ui/design-system/components/platform-spinner/playwright.spec.py -v
```
