# Основные инструкции: вход, Dashboard и меню пользователя

Базовый маршрут для нового пользователя: открыть сайт, перейти в Dashboard, понять список сервисов и разобраться с пунктами меню пользователя.

## Шаг 1. Открываем Dashboard компании. Здесь собраны основные сервисы.

![Открываем Dashboard компании. Здесь собраны основные сервисы.](main-dashboard-user-menu--01-open-the-company-dashboard-with-the-main-services.png)

## Шаг 2. Dashboard показывает основные сервисы компании. Системные сервисы здесь не показываются обычной компании.

![Dashboard показывает основные сервисы компании. Системные сервисы здесь не показываются обычной компании.](main-dashboard-user-menu--02-dashboard-shows-the-company-s-main-services-system-only-services.png)

## Шаг 3. Открываем меню пользователя. Здесь находятся сервисы, профиль, компания, календарь, документация, язык, тема и выход.

![Открываем меню пользователя. Здесь находятся сервисы, профиль, компания, календарь, документация, язык, тема и выход.](main-dashboard-user-menu--03-open-the-user-menu-it-contains-apps-profile-company-calendar.png)

## Шаг 4. Пункт с названием компании раскрывает список компаний. Галочка показывает текущую компанию, а Create company создает новую компанию.

![Пункт с названием компании раскрывает список компаний. Галочка показывает текущую компанию, а Create company создает новую компанию.](main-dashboard-user-menu--04-the-company-row-opens-the-company-list-the-checkmark-shows.png)

## Шаг 5. Пункт Apps открывает витрину сервисов. Это быстрый способ перейти в Flows, NetWorkle, RAG, Sync или Documents.

![Пункт Apps открывает витрину сервисов. Это быстрый способ перейти в Flows, NetWorkle, RAG, Sync или Documents.](main-dashboard-user-menu--05-apps-opens-the-service-launcher-it-is-a-quick-way-to-go-to-flows.png)

## Шаг 6. Пункт Profile открывает карточку пользователя: имя, email, роли и действия с аккаунтом.

![Пункт Profile открывает карточку пользователя: имя, email, роли и действия с аккаунтом.](main-dashboard-user-menu--06-profile-opens-the-user-card-with-name-email-roles-and-account.png)

## Шаг 7. Нижние пункты меню: Documentation открывает справку, Language меняет язык, Theme переключает тему, Logout выходит из аккаунта.

![Нижние пункты меню: Documentation открывает справку, Language меняет язык, Theme переключает тему, Logout выходит из аккаунта.](main-dashboard-user-menu--07-the-lower-menu-items-documentation-opens-help-language-changes.png)

## Шаг 8. Пункт Calendar открывает календарь на весь экран. Модалка не уезжает за край окна и готова к работе.

![Пункт Calendar открывает календарь на весь экран. Модалка не уезжает за край окна и готова к работе.](main-dashboard-user-menu--08-calendar-opens-the-fullscreen-calendar-the-modal-stays-inside.png)
