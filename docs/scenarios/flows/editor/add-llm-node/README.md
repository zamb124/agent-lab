# Flows: добавление LLM-ноды

Инструкция показывает, как добавить LLM Node на канву, открыть настройки ноды, заполнить промпт и выбрать LLM-профиль.

## Шаг 1. Открываем редактор flow. Слева находится палитра нод, в центре находится канва.

![Открываем редактор flow. Слева находится палитра нод, в центре находится канва.](add-llm-node--01-otkryvaem-redaktor-flow-sleva-nakhoditsya-palitra-nod-v-tsentre.png)

## Шаг 2. Перетаскиваем LLM Node из палитры на канву. Справа открываются настройки выбранной ноды.

![Перетаскиваем LLM Node из палитры на канву. Справа открываются настройки выбранной ноды.](add-llm-node--02-peretaskivaem-llm-node-iz-palitry-na-kanvu-sprava-otkryvayutsya.png)

## Шаг 3. Заполняем промпт и LLM-настройки. Промпт говорит агенту, как вести себя с пользователем.

![Заполняем промпт и LLM-настройки. Промпт говорит агенту, как вести себя с пользователем.](add-llm-node--03-zapolnyaem-prompt-i-llm-nastroyki-prompt-govorit-agentu-kak.png)

## Шаг 4. Нажимаем Publish. Так черновик сохраняется, и flow можно запускать или продолжать редактировать позже.

![Нажимаем Publish. Так черновик сохраняется, и flow можно запускать или продолжать редактировать позже.](add-llm-node--04-nazhimaem-publish-tak-chernovik-sokhranyaetsya-i-flow-mozhno.png)
