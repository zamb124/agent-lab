# Ожидание оператора в виджете на сайте

**Для чего:** эта инструкция покажет, как покупатель на сайте магазина видит ожидание оператора в том же виджете, что и обычный чат агента.

**Какие проблемы решает:** спорный возврат с внешнего сайта не должен выглядеть как «чат сломался» — нужна понятная плашка и заблокированный ввод в режиме одного ответа.

**Результат:** в embed-виджете видна плашка ожидания, поле ввода только для чтения.

## Шаг 1. Откройте виджет чата на сайте

На внешней странице магазина нажмите кнопку виджета. Откроется тот же чат агента, что в Flows, только встроенный в сайт.

![Откройте виджет чата на сайте](hitl-embed-waiting-banner--01-embed-widget-open.png)

## Шаг 2. Опишите спорный возврат

Напишите, что нужен оператор по возврату без чека. Агент передаёт обращение в очередь поддержки.

![Опишите спорный возврат](hitl-embed-waiting-banner--02-embed-hitl-sent.png)

## Шаг 3. Дождитесь плашки ожидания — поле ввода заблокировано

В виджете появляется плашка, что запрос у оператора, а поле ввода становится недоступным — в режиме одного ответа покупатель не может отправить ещё одно сообщение.

**Итог.** На сайте магазина HITL выглядит так же, как в кабинете: плашка ожидания и заблокированный ввод.

![Дождитесь плашки ожидания — поле ввода заблокировано](hitl-embed-waiting-banner--03-embed-waiting-banner.png)
