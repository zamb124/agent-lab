# Отбор партий по FEFO: сначала то, что скорее испортится

**Для чего:** на складе несколько партий одного товара с разными сроками — отгружать надо раньше испорченное, иначе свежая партия уйдёт, а старая сгниёт на полке.

**Какие проблемы решает:** склад с FEFO-стратегией сам резервирует партию с ближайшим «годен до» — терминал ведёт оператора именно за ней, а не за удобной с верхней полки.

**Результат:** из двух партий система зарезервировала и отобрала раннюю, остаток ранней уменьшился, поздняя цела.

## Шаг 1. Подсказка ведёт за партией с ближайшим сроком

Строка документа уже зарезервировала раннюю партию — подсказка ведёт к её ячейке. Оператору не нужно сравнивать даты на этикетках: выбор сделала стратегия склада.

![Подсказка ведёт за партией с ближайшим сроком](stock-tsd-fefo-pick--01-tsd-fefo-expected.png)

## Шаг 2. Отсканируйте ячейку — списана именно ранняя партия

**Демонстрация результата.** Остаток ячейки «8»: из 10 штук списаны 2 именно партии «годен до +10 дней» — проверить можно в разделе «Партии» на компьютере, где каждая партия показывает свой срок.

**Итог.** На FEFO-складе партии с ближайшим сроком уходят первыми автоматически — оператору остаётся сканировать то, куда ведёт терминал.
