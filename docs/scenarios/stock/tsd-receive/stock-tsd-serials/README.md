# Приёмка серийных устройств: один скан — одна штука

**Для чего:** технику и дорогие товары учитывают по серийным номерам — каждая единица уникальна, по ней идут гарантия и возвраты.

**Какие проблемы решает:** терминал знает, что серийник — это всегда ровно одна штука: поле количества не показывается вообще, ввод номера сразу фиксирует единицу. Повторный серийник система не пропустит — одна единица не может лежать на складе дважды.

**Результат:** три серийных устройства приняты по одному скану каждое, остаток — три позиции по штуке под своими SN.

## Шаг 1. Введите серийный номер первого устройства

Для серийного товара на шаге количества — одно поле серийника, цифровой клавиатуры нет: система сама ставит количество 1. После подтверждения строка сразу фиксируется.

![Введите серийный номер первого устройства](stock-tsd-serials--01-tsd-serial-entry.png)

## Шаг 2. Добавьте остальные серийники

Каждый серийник — своя строка исполнения: после фиксации сканируйте товар и вводите следующий номер. Список строк показывает все SN до проводки.

![Добавьте остальные серийники](stock-tsd-serials--02-tsd-serial-lines.png)

## Шаг 3. Отсканируйте ячейку — три устройства на остатке

**Демонстрация результата.** Ячейка показывает остаток «3» — три принятых устройства, каждое под своим серийником. По ним система узнает конкретную единицу при отгрузке и возврате.

**Итог.** Серийный товар принимается по одному скану на единицу — без поля количества; дубликат номера система отклонит.
