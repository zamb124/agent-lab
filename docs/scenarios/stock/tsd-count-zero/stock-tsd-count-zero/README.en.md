# Counting down to zero: «bin is empty» is a fact too

**Purpose:** the operator reached the bin and physically sees emptiness — the system must accept a zero fact instead of forcing a fake quantity.

**Problems solved:** zero is a legal quantity only in counting: recorded as the count fact and produces a variance for approval, instead of «quantity must be greater than zero» rejection.

**Result:** fact 0 written onto the bin stock, variance −5 visible to the system.
