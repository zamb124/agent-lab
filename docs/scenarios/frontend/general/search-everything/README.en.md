# Search with the platform engine

**Purpose:** use the console's «Search» page to find information on the web with the built-in engine.

**Problems solved:** you need a quick answer without opening another site: search shows the sources used and the results.

**Result:** a search run with results and sources listed below the box.

## Step 1. Open the «Search» page

In the console open «Search»: a single box in the middle, like the engines you already know. Below it lists the sources the engine will use.

![Open the «Search» page](search-everything--01-search-home.png)

## Step 2. Type the question and press Enter

**Result demonstration.** Once the question is typed and Enter pressed, results arrive below the box with title, source address and an excerpt. One click opens the original page.

**Summary.** Search lives inside the console: query the engine and read the sources without leaving.

![Type the question and press Enter](search-everything--02-search-results.png)
