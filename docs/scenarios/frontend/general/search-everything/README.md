# Поиск встроенным движком платформы

**Для чего:** страница «Поиск» в консоли ищет информацию в интернете встроенным движком.

**Какие проблемы решает:** нужен быстрый ответ, не открывая другой сайт: поиск показывает использованные источники и результаты.

**Результат:** поиск выполнен, результаты и источники видны под строкой запроса.

## Шаг 1. Откройте страницу «Поиск»

В консоли откройте «Поиск»: одна строка по центру, как у привычных поисковиков. Ниже — источники, которые будет использовать движок.

![Откройте страницу «Поиск»](search-everything--01-search-home.png)

## Шаг 2. Напишите вопрос и нажмите Enter

**Демонстрация результата.** Написали вопрос и нажали Enter — результаты появляются под строкой: заголовок, адрес источника и выдержка. Один клик открывает оригинальную страницу.

**Итог.** Поиск внутри консоли: движок отвечает, источники читаются не выходя.

![Напишите вопрос и нажмите Enter](search-everything--02-search-results.png)
