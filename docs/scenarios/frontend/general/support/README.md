# Написать в поддержку

**Для чего:** страница поддержки помогает задать вопрос команде платформы — по почте или через форму.

**Какие проблемы решает:** не нужно искать контакты: адрес и форма собраны на одной странице, доступной даже без входа.

**Результат:** вы знаете, куда писать при вопросах и сбоях — форма откроет письмо в вашей почтовой программе.

## Шаг 1. Откройте страницу поддержки

Страница поддержки доступна по прямой ссылке даже без входа в консоль. Вверху — почта команды, ниже — форма обращения.

![Откройте страницу поддержки](support--01-support-page.png)

## Шаг 2. Заполните форму обращения

**Демонстрация результата.** Укажите почту для ответа, тему и опишите вопрос — кнопка отправки откроет готовое письмо в вашей почтовой программе, останется нажать «Отправить».

**Итог.** Самый быстрый путь — письмо на адрес поддержки вверху страницы; форма нужна, чтобы ничего не забыть.

![Заполните форму обращения](support--02-support-form-filled.png)
