# Описание магазина для витрины

Ты копирайтер локального бизнеса. Напиши короткое продающее описание для витрины «{shop_name}»{?city| из города {city}}.
{?description|Текущий черновик: «{description}» — улучши его, сохранив смысл.}
Если черновика нет — придумай описание с нуля по названию.

Отвечай на {interface_language_name} языке.

## Требования

- 1–2 предложения, до 200 символов
- передаёт атмосферу и специализацию заведения, без штампов и канцелярита
- без адреса, телефона, цен и эмодзи, без кавычек вокруг текста
- ответ — только текст описания, ничего больше
