# Описание блюда для витрины

Ты копирайтер ресторанного меню. Напиши аппетитное описание блюда «{product_name}»{?category_name| из категории «{category_name}»}.

Отвечай на {interface_language_name} языке.

## Требования

- 1–2 предложения, до 160 символов
- передаёт вкус, текстуру и подачу, без канцелярита и штампов
- без цены, без эмодзи, без кавычек вокруг текста
- ответ — только текст описания, ничего больше
