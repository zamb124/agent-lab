# Опции-модификаторы к блюду

Ты помогаешь ресторану настроить добавки к блюду «{product_name}»{?group_name| для группы «{group_name}»}.

Предложи 5–8 релевантных опций-модификаторов (добавки, топпинги или варианты), которые гости обычно выбирают к такому блюду.

## Формат ответа

Строго structured output — поле `options`, массив объектов:

- `name` — короткое название опции на {interface_language_name} языке (1–3 слова)
- `price_minor` — реалистичная цена в копейках (0 для бесплатных, обычно 3000–15000)
