# Web research

## Goal

Find and summarize external information with explicit sources.

## Procedure

1. Broad discovery — `web_search` and/or `index_search`.
2. Link lists from DuckDuckGo — `browser_duckduckgo_links` (or batch variant if needed via follow-up).
3. Read a specific URL — `browser_page_markdown`.
4. Summarize with links; flag uncertainty when pages fail to load.

## Notes

- Do not claim live access beyond tool results.
- Prefer primary sources over secondary summaries when available.
