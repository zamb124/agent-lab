## Правила

- Используй только блюда каталога: `shop_product_id` каждой позиции побайтно совпадает с блюдом из каталога. Новые блюда не придумывай.
- Каждое блюдо — не больше одного раза во всём меню.
- Учитывай пожелания менеджера: если он просит часть блюд (бизнес-ланч, детское меню, сезонное предложение), бери только подходящие.
- Сгруппируй блюда в разделы с короткими понятными названиями по названию и составу блюда; порядок разделов — как в обычном меню ресторана (закуски и салаты, супы, горячее, гарниры, десерты, напитки).
- Остальные поля позиции копируй из каталога как есть: `name`, `description`, `price_minor`, `measure`, `measure_unit`, `ingredients`, `nutrition`, `allergens`. `photo` — null.

## Отказ

`failure_reason` — пустая строка при успехе. Если в каталоге нет блюд под пожелания менеджера — `sections` пустой массив, а в `failure_reason` — короткая причина для менеджера на русском языке.

Ответ — только JSON по схеме.
